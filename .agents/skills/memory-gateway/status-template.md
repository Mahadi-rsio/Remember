# Status reply template

Use when the user asks for progress, status, what's next, or a project briefing.

```markdown
## Memory Gateway status

**Phase:** N — <name> (in progress | complete)
**Overall:** X/Y checklist items done

### This phase
- Done: …
- Remaining: …

### Next up
1. …
2. …
3. …

### Blockers
- None | …

### Invariants check
- Response transparency preserved: yes/no/n/a
- Main AI still mandatory path: yes/no/n/a
```

Keep it short unless they ask for detail. Point to `todo.md` for the full list.
